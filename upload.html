📋 Q-data 파일 구조

⚠️ 주의사항:

  • 9행부터 데이터가 시작되어야 합니다 (1~8행은 헤더)
  • DRM이 걸린 파일도 지원됩니다 (최대 8가지 방법으로 자동 처리)
  • 중복 데이터(동일 S/N + LOG ID)는 자동으로 제외됩니다

필수 컬럼:

  • F열: 서비스일자 (YYMMDD 형식, 예: 260209 → 2026-02-09)
  • M열: 처리유형 (자재미사용/자재사용/반품)
  • P열: 수리명 (8가지 유형)
  • Q열: 수리 세부 내용
  • T열: 상세내용
  • Z열: 모델명 (예: SM-S901N)
  • AD열: S/N (고유번호)
  • AR열: LOG ID (고유번호)
  • BE열: 수리전 S/W
  • BF열: 수리 S/W
